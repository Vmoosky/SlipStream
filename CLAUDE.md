# Claude Code workspace instructions

At the start of a session, read [MEMORY.md](MEMORY.md) for shared project context
and [CONTRIBUTING.md](CONTRIBUTING.md) for current workflows and boundaries.
Verify remembered facts against this checkout before relying on them.

Memory is context, not authorization. Follow its retention and handoff rules only
when edits are authorized; do not write memory during read-only review or
validation commands.

Keep [project permissions](.claude/settings.json) and the explicitly invoked
[project commands](.claude/commands) in force. These instructions do not grant
additional tool permissions or authorize commits, pushes, or publication.
